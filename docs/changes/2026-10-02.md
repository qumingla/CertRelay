# 2026-10-02 证书自动化、任务恢复与控制台优化

本次改动按三个 PR 依次合并到 `main`，每个 PR 单独说明问题、改动与验证。

## 1. 自动续期与节点下发（PR #6）

- 新增随服务启动的后台调度器，每 30 秒检查启用的域名，按配置的到期前天数续期，并为节点排队下发新证书。
- 续期失败冷却 1 小时，下发失败冷却 5 分钟；避免重复排队，用户明确删除的证书不会立即重新下发。
- 保存节点分配保留部署状态，无效域名导致更新回滚；旧证书回报不能把新证书标为已同步。
- 主控子进程限制 30 分钟；证书导出、WebDAV 上传移出事件循环。SQLite 增加 WAL、锁等待和查询索引，日志在数据库内追加，任务耗时使用 UTC。
- 概览接口提供调度检查时间、续期阈值和待下发数量。

## 2. 卡住任务的超时恢复（PR #7）

- 部署、删除和 Agent 升级命令从排队开始计时，30 分钟没有完成回执则失败；命令丢失的旧任务也自动结束。
- 其他主控任务 35 分钟无进度则失败。续期正在执行时，调度器仍然每 30 秒检查任务。
- 节点获取命令和提交回执前检查超时；任务和命令采用条件更新，迟到回执不会覆盖终态。
- 失败日志包含原因及结束时间。已有页面轮询可显示更新。
- 该逻辑不强制终止节点上已经运行的进程。

## 3. 控制台 UI 与前端性能

- 调整主色、圆角和键盘焦点样式；概览增加刷新按钮、骨架屏以及自动续期和下发状态。
- 优先显示异常或即将到期的证书，缩小表格最小宽度，改善窄屏使用。
- 合并历史和实时事件并去重，忽略 SSE 保活消息。
- 路由按需加载，查询数据默认保留 15 秒新鲜期，减少重复请求。
